# tools

对应包：`tools`

本文只讲这一个包。用它注册进去的那些工具——待办、目标、后台作业、MCP 桥接、子 agent 控制、技能调用——各有各的文档，不在这里；审批的实现方、超时与重复提醒也一样。

## 定位

一个 agent 要会用工具。最省事的做法是把工具做成一张全进程共用的函数清单：模型点个名，程序照着调。

```mermaid
flowchart LR
    subgraph BAD["一张全进程共用的函数清单"]
        A1["模型点名"] --> A2["查清单"] --> A3["直接调"]
        A3 -.->|"每个 agent 看见的都一样<br/>发不出定制的能力清单"| A1
        A3 -.->|"工具写错一个下标<br/>整个进程一起没"| A1
        A3 -.->|"失败是一个异常<br/>模型认不得 会话日志里也没这条"| A1
    end
```

这个包做的是另一件事：

```mermaid
flowchart LR
    subgraph GOOD["按作用域算出来的清单 ＋ 一条派发管线"]
        B1["模型点名"] --> B2["先算这个 agent<br/>此刻看得见哪些"]
        B2 --> B3["过一条四段管线<br/>裁决 执行 收尾"]
        B3 --> B4["一份可以落库的结果<br/>成功失败都是它"]
        B4 -.->|"每个 agent 各有各的清单"| B2
        B4 -.->|"第三方代码炸了<br/>只炸这一次调用"| B3
        B4 -.->|"失败也是一条工具结果<br/>重放时一条不少"| B1
    end
```

所以它只回答两个问题：

```mermaid
flowchart TD
    Q["tools 回答两件事"] --> Q1["一、这个 agent 此刻<br/>看得见哪些工具"]
    Q --> Q2["二、一次调用怎么从<br/>「模型点了个名」<br/>跑到「一份可以落库的结果」"]
```

## 架构：六样东西，不会有第七样

```mermaid
flowchart TD
    D["一个工具的定义"] --> R["运行时：注册表 ＋ 派发管线"]
    L["一个作用域的那一格登记"] --> R
    R --> V["一次遍历算出来的可见性视图"]
    V --> E["一次跑起来的调用"]
    E --> RES["一份结果"]
```

### 运行时手里握着什么

```mermaid
flowchart LR
    RT["运行时"] --> LY["按作用域分格的登记<br/>全局那一格 ＋ 各作用域各一格"]
    RT --> AP["审批接缝<br/>可以不接"]
    RT --> LG["一个记日志的地方<br/>用来报第三方代码的崩溃"]
    RT --> MB["参数字节上限<br/>缺省 1 MiB"]
```

按作用域分格这件事不是本包发明的，是作用域那一层提供的现成能力，本包只是它十来个使用方之一。

### 一格登记里有七样东西

```mermaid
flowchart LR
    TL["一个作用域的那一格"] --> t1["工具定义"]
    TL --> t2["对继承来的工具的限制"]
    TL --> t3["只能拒绝的守卫"]
    TL --> t4["执行前的裁决链"]

    TL --> t6["执行后的改判链"]
```

第一样是**具名的**，其余六样**不具名**：

```mermaid

    B["另外六样"] --> B1["允许重复登记"]

```


## 能力一：一个 agent 看得见哪些工具

一个进程里活着很多 agent，agent 挂在预设下面。工具、限制、守卫全都按这条链继承。

```mermaid
flowchart LR
    G["全局那一格"] --> I["继承面<br/>近的盖远的"]
    A1["远祖先那一格"] --> I
    A2["近祖先那一格"] --> I
    I -->|"整条链上的限制全部施加<br/>取交集"| FI["过滤之后的继承面"]
    FI --> V["真正看得见的那些"]
    OWN["自己那一格"] -->|"一条也不过滤"| V
```

一次自下而上的遍历，同时算出四样东西：

```mermaid
flowchart TD
    W["一次遍历"] --> W1["真正看得见的那些定义"]
    W --> W2["稳定的排列顺序"]
    W --> W3["过滤之前的名字全集"]
    W --> W4["一条限制可以点名的范围"]
```

### 自己注册的不受限制影响

这条豁免是「按子 agent 发一份定制能力清单」能成立的前提：

```mermaid
flowchart TD
    A["给子 agent 注册一个<br/>它专用的结构化答话工具"] --> B["注册在子 agent 自己那一格"]
    C["父 agent 给它一份过滤器<br/>「这个孩子只能用这几样」"] --> D{"过滤器管得着<br/>它自己那一格吗"}
    D -->|"管不着（当前做法）"| E["答话的机器留着<br/>孩子说得出话"]
    D -.->|"如果管得着"| F["连它答话的机器<br/>一起被摘掉"]
```

历史上有过一次读错：

```mermaid

        X2 --> X3["它们变成了祖先的贡献"]
```

## 能力二：一切失败都是结果，不是错误

```mermaid
flowchart LR
    subgraph BAD4["失败走错误通道"]
        A1["工具炸了 / 参数不合法"] --> A2["返回一个错误"]
        A2 --> A3["会话日志里少了一条"]
        A3 --> A4["重放时那次调用悬在那儿<br/>没有配对的结果"]
    end
```

```mermaid
flowchart LR
    subgraph GOOD4["失败也是一份结果（当前做法）"]
        B1["工具炸了 / 参数不合法"] --> B2["一份标着「这是错误」的结果"]
        B2 --> B3["和成功那份在日志里<br/>是同一种东西"]
        B3 --> B4["重放一条不少"]
    end
```

理由只有一句：这条管线的出口是**模型**，而模型只认得工具结果，认不得 Go 的错误。

### 九种失败各自的分类码

```mermaid
flowchart TD
    F["一次调用失败了"] --> G{"哪一类"}
    G --> C1["点名了看不见的工具<br/>→ UNKNOWN_TOOL"]
    G --> C2["参数不是合法 JSON<br/>或不符合参数形状<br/>→ INVALID_ARGS"]
    G --> C3["参数超过字节上限<br/>→ INVALID_ARGS"]
    G --> C4["交出的值不符合返回值契约<br/>→ INVALID_TOOL_OUTPUT"]
    G --> C5["schema 自身超出支持的子集<br/>→ UNSUPPORTED_SCHEMA"]
    G --> C6["执行体已经起步 中途被取消<br/>→ ABORTED"]
    G --> C7["执行体还没起步就被取消<br/>→ ABORTED_BEFORE_DISPATCH"]
    G --> C8["执行前的裁决或守卫拒绝<br/>→ 不带分类码"]
    G --> C9["执行后的改判拦下<br/>→ 不带分类码"]
```

最后两种为什么不带分类码：

```mermaid
flowchart LR
    A["拒绝的理由是<br/>策略现写的一句话"] --> B["不是一个有身份的错误类"]
    B --> C["硬安一个分类码<br/>等于给它一个假身份"]
```

## 能力四：把一份结果定形

### 判据是「值变没变」，不是「这份结果是不是本包造的」

```mermaid
flowchart TD
    A["壳交回来一份结果"] --> B{"里面的值<br/>和本包最近验过的那个<br/>一样吗"}
    B -->|"一样"| C["原样放行<br/>壳对内容的改写被保留"]
    B -->|"不一样"| D["按契约重新验、重新渲染<br/>壳自己写的内容在这里丢掉"]
    D -.->|"内容必须是「那个值」<br/>渲染出来的"| D
```

为什么不能按出身判：

```mermaid
flowchart LR
    subgraph BAD7["按出身判"]
        A1["记住哪些结果是原件"] --> A2["一个壳复制一份<br/>再改个字段"]
        A2 --> A3["复制件和原件<br/>在 Go 里完全一样"]
        A3 --> A4["认不出来"]
    end
```

原来那套 TypeScript 代码靠的是 JS 的对象身份，那条路在 Go 这边立不住——Go 的结构体是值。

### 定形做两遍

```mermaid
flowchart LR
```

## 失败语义

```mermaid
flowchart TD
    A["出岔子了"] --> B{"是装配期还是调用期"}
    B -->|"装配期：注册、加限制、登记扩展点"| C["返回错误<br/>这些都是编程错误<br/>就该在装配时炸"]
    B -->|"调用期：任何一种失败"| D["不返回错误<br/>返回一份标着「这是错误」的结果"]
```

| 什么时候 | 返回什么 | 调用方该做什么 |
|---|---|---|
| 定义不合法（名字、执行体、schema、超时预算） | 「定义不合法」这一类错误 | 改定义 |
| 限制点名了不存在的全局工具 | 「限制不合法」这一类错误 | 对照报错里列出的现有名字 |
| 在没有身份的作用域上加限制 | 「限制不合法」这一类错误 | 用那个 agent 自己的作用域 |
| 一条什么都没点名的限制 | 「限制不合法」这一类错误 | 至少点名一样 |
| 登记一条空的规则或守卫 | 普通错误 | 补上参数 |
| 同一格里重名注册 | 重名错误 | 换名字，或改用那个 agent 的作用域 |
| **一次调用的任何失败** | **不返回错误** | 读结果上的「是不是错误」和那份分类 |
