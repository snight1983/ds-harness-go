# 移植与文档门禁工具

对应包：`internal/devtools/` 底下的十一个包

## 定位

这个仓库是把一套 TypeScript 的东西重做成 Go。这件事有两个说不清楚的地方：

```mermaid
flowchart TD
    Q1["原来那套东西里的每一样<br/>在这边是做了、没做、还是不用做"] --> A1["得有一本账"]
    Q2["这边写下的每一条规矩<br/>（谁能碰数据库、谁能碰磁盘、谁在谁上面）"] --> A2["得有人盯着"]
```

靠人记是记不住的：

```mermaid
flowchart LR
    A["一条只写在文档里的规矩"] --> B["某天有人写了一行违反它的代码"]
    B --> C["评审时没看出来"]
    C --> D["那道墙就没了"]
    D -.->|"而且是悄悄没的<br/>下一次没人知道它曾经存在"| D
```

所以这些工具存在的理由是同一句话：**把规矩变成会变红的东西。**

```mermaid
flowchart LR
    A["这些命令"] --> B["是仓库维护工具"]
    B --> C["不会链接进运行时"]
```

## 架构与工具清单

```mermaid
flowchart TD
    subgraph LEDGER["移植账本这一路"]
        P1["portmap<br/>扫出原来那套东西的全部导出"]
        P2["portcheck<br/>同步账本 / 执行移植门禁"]
        P3["rule<br/>一次改一行裁决"]
        P4["capmap<br/>由裁决生成能力覆盖资料"]
        P5["rulingtable<br/>账本文件的读写实现，三方共用"]
    end
    subgraph GATE["边界门禁这一路"]
        G1["dbcheck<br/>除了持久化那一层，谁都不许知道下面是个数据库"]
        G2["oscheck<br/>业务代码不许碰这台机器的磁盘"]
        G3["layercheck<br/>低档不许 import 高档"]
        G4["consumercheck<br/>仓库外引得进来吗"]
        G5["doccheck<br/>每个包都有文档，导航不断链"]
    end
    T["toolpath<br/>仓库根在哪、原始快照在哪"] --> LEDGER
    T --> GATE
```

| 工具 | 吃什么 | 答什么 |
|---|---|---|
| `portmap` | 原来那套 TypeScript 源码 | 一份导出符号清单 |
| `portcheck` | 符号清单 ＋ 裁决表 ＋ Go 源码 | 同步裁决表，或执行移植门禁 |
| `rule` | 一个包、一个符号、一个裁决 | 安全地更新一行裁决记录 |
| `capmap` | 能力定义 ＋ 包裁决 | 能力覆盖资料 |
| `doccheck` | 包清单 ＋ 包映射 ＋ Markdown | 每个包都有文档，且导航完整 |
| `consumercheck` | 包清单 ＋ 本仓库的模块声明 | 在仓库外建一个模块，验公开路径和每个公开包对外可引 |
| `dbcheck` | 整棵目录树的 Go 源码 | 谁在碰数据库 |
| `oscheck` | 整棵目录树的非测试 Go 源码 | 谁在碰本机磁盘 |
| `layercheck` | 整棵目录树的 import 关系 | 有没有反方向的依赖 |

## 仓库外消费门禁

### 它解决的是一类仓库内部验不出来的错

```mermaid
flowchart TD
    A["模块声明写的是一个短名字"] --> B["代码里的 import 写的是完整的托管路径"]
    B --> C{"编译时怎么解析"}
    C -->|"仓库内部"| D["走主模块自己的声明加相对路径<br/>全绿"]
    C -->|"外部宿主引进来"| E["找不到这个包"]
    E -.->|"仓库内的任何一次构建<br/>都撞不上这个"| E
```

### 它怎么验

```mermaid
sequenceDiagram
    participant C as consumercheck
    participant T as 临时目录里的一个模块
    C->>T: 摆出一个模块名不属于本仓库的消费方
    C->>T: 声明依赖公开路径，并指到本地检出
    C->>T: 生成一个程序，空引全部可发布包
    C->>T: 构建 —— 证明引得进来
    C->>T: 静态检查 —— 证明引进来是像话的
    C->>T: 运行最小闭环 —— 证明跑得起来
```

最小闭环那一步做的事：建作用域 → 建会话存储 → 建会话 → 追加一条用户消息 → 读回来。

### 依赖清单直接照录，不重新解一遍

```mermaid
flowchart LR
    A["这道门禁验的是路径能不能引<br/>不是依赖解析"] --> B["重新联网解一遍"]
    B -.->|"只会把网络抖动算进失败里"| B
```

### 那个程序里还压着一条接缝

```mermaid
flowchart LR
    A["一条编排器与会话存储之间的接缝"] --> B["一度装不起来<br/>（一边交出的是准备期，另一边声明的是会话）"]
    B --> C["而两边各自的测试都绿着"]
    C --> D["外部装配方是唯一撞得上它的人"]
    D --> E["所以那句断言写在这个外部程序里"]
```

## 数据库边界门禁

它守的就是[持久化抽象层](datastore.md)那条界线。

```mermaid

    A --> B2["装配点：可以开连接池、挂驱动<br/>但不许自己拼 SQL"]
    A --> B3["门禁工具自己：可以引持久化层<br/>（不然诊断不了它），但不许开池"]
    A --> B4["其余一律按业务包管"]
```

### 它自己整个跳过自己

```mermaid
flowchart LR

```

## 文件系统边界门禁

它是同一件事的另一半：数据库那一半管库，这一半管内容存储。

```mermaid
flowchart TD
    A["这个服务跑的地方没有可用硬盘"] --> B["存储全部落在数据库和对象存储上"]
    B --> C["为的是它能分布式部署"]
    D["一旦某处代码隐含<br/>「有那么一台机器、有那么一个文件系统」"] --> E["这个服务就被绑死成单点"]
```

```mermaid
flowchart LR
    A["内容读写整个收在一条文件系统接缝上"] --> B["而这件事光靠约定守不住"]
    B --> C["只要有一个人写下一行直接读本机文件的代码"]
    C --> D["那道墙就没了，还是悄悄没的"]
```

### 两条规则

```mermaid
flowchart TD
    R1["① 不许调标准库里那些碰文件系统的函数"] --> R1a["打开、读写、建删、改名、取工作目录"]
    R2["② 不许 import 宿主机路径语法那两个包"] --> R2a["盘符、反斜杠、符号链接<br/>都是宿主机的概念"]
    R2a --> R2b["本仓库的路径一律斜杠分隔、由后端解释<br/>拼路径用纯路径那个包"]
```

```mermaid
flowchart LR
    A["那个标准库包的其余部分不管"] --> B["读环境变量、退出进程、写标准输出"]
    B --> C["和磁盘没有关系"]
```

### 只查非测试文件

```mermaid
flowchart LR
```

## 移植账本

### 每个导出只能处于五种状态之一

```mermaid
flowchart TD
    S{"一个原始导出"}
    S --> S1["还没裁决"] --> X1["门禁失败"]
    S --> S2["已经实现"] --> X2["必须给出 Go 这边的符号引用"]
    S --> S3["Go 已有等价物"] --> X3["必须说明依据"]
    S --> S4["明确不做"] --> X4["必须说明原因"]
    S --> S5["当前范围外"] --> X5["产品外壳这类"]
```

### 一次只许改一行

```mermaid
flowchart TD
    A["改一行裁决"] --> B{"三种情况拒绝写入"}
    B --> B1["匹配有歧义"]
    B --> B2["要覆盖一行已经裁决过的"]
    B --> B3["没给依据"]
    A --> C["这样每次判断在版本历史里都看得清"]
```

## 能力边界

```mermaid
flowchart TD
    Y["这些工具能证明的"] --> Y1["有裁决、有映射、格式自洽"]
    N["证明不了的"] --> N1["设计判断是对的"]
    N --> N2["标了「已经实现」不等于行为完全等价<br/>仍然要测试和人工审查"]
    N --> N3["生成的文件替代不了源码与许可证审查"]
```

```mermaid
flowchart TD
    A["各道门禁各自的盲区"] --> A1["文档门禁只校验覆盖和本地链接<br/>不评价文字质量"]
    A --> A2["数据库门禁认的是 import 和字符串字面量<br/>拦不住把 SQL 拼在运行期的写法"]
    A --> A3["磁盘门禁认的是语法上的调用<br/>拦不住经由反射或第三方库间接摸到磁盘"]
    A --> A4["消费方门禁指的是本地检出<br/>所以证明不了「这个版本在模块代理上取得到」"]
    A4 -.->|"那要等打了标签之后才验得了"| A4
```

```mermaid
flowchart LR
    A["两道边界门禁守的是同一句话"] --> B["「别在别处开这扇门」"]
    B -.->|"不是「别写出坏 SQL」<br/>也不是「别做坏 IO」"| B
```
