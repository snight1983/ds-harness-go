# 工作流与 Ralph

对应包：`feature/workflow`、`feature/workflow/toolralph`

## 定位

一件长活儿交给一个模型从头做到尾，做着做着会出一件事：早先那些试错、走岔的路、已经作废的假设，全堆在同一段对话里。越往后，它要读的废话越多，也越容易被自己早先的错误判断绕进去。

```mermaid
flowchart LR
    subgraph N["一个人从头干到尾"]
        A1["第 1 小时：清爽"] --> A2["第 3 小时：一半是废弃方案"] --> A3["第 5 小时：它在跟三小时前的自己吵架"]
    end
```

Ralph 的答案是**每一轮换一个人**：

```mermaid
flowchart LR
    subgraph Y["每轮换一个人"]
        B1["新人只拿到两样东西"] --> B2["一个从头到尾一个字不改的目标"]
        B1 --> B3["上一轮留下的一份很短的交接"]
        B2 --> B4["它看不到父的对话<br/>也看不到上一个人的会话"]
        B3 --> B4
    end
```

关键的一步不在「换人」，在**长期记忆搬了家**：

```mermaid
flowchart TD
    A["原来：长期记忆 = 一段越来越长的对话"] --> B["于是记忆越多越脏"]
    C["现在：长期记忆 = 那个共享的工作区，以及它当下的工作树"] --> D["于是每一轮都去看真东西<br/>而不是去读别人对真东西的回忆"]
    E["交接那份 JSON"] -.->|"只是路标，不是证据<br/>提示词里明写「拿工作区去核」"| C
```

这一篇覆盖两个包，一个是**接缝**，一个是**跑在这类接缝上的那件事**：

```mermaid
flowchart LR
    S["编排工作流那条能力接缝"] --> S1["一次运行怎么开工、怎么结清<br/>中途往外说什么"]
    S --> S2["只有契约，一行编排都不跑"]
    R["那件面向模型的 Ralph 工具"] --> R1["固定的多轮子 agent 流程"]
    R --> R2["父发起一个目标<br/>按轮开新的孩子、收报告、决定继不继续"]
```

### 这个仓库里没有工作流引擎

```mermaid
flowchart TD
    A["DSH 那台引擎跑的是<br/>一段 JavaScript 编排脚本"] --> B["载体是一条 Node worker 线程"]
    B --> C["这两样本仓库都没有"]
    C --> D["引擎裁掉"]
    C --> E["它唯一的消费方——那件通用脚本工具——跟着裁掉"]
    C --> F["接缝留下"]
    F -.->|"观察方可以先于引擎存在<br/>将来补一台 Go 引擎，不必推翻已经装上去的观察者"| F
```

Ralph 不读脚本：它的编排在这里就是一个写死的循环。

## 架构

```mermaid
flowchart TD
    M(("模型")) -->|"给一个目标"| T["Ralph 工具"]
    T --> G["开工前的几道关"]
    G --> L["轮次循环"]
    L -->|"第 1 轮"| C1["一个全新的孩子"] --> P1["一份结构化报告"]
    P1 -->|"还要继续"| L
    L -->|"第 2 轮"| C2["又一个全新的孩子"] --> P2["一份结构化报告"]
    P2 -->|"还要继续"| L
    L --> F["三种收场：报完成 / 报阻塞 / 轮次用光"]
    F --> O["排成一段交回父手上的文字"]
    O --> M
    W[("共享工作区")] -.-> C1
    W -.-> C2
    W -.->|"真正的长期记忆在这儿"| W
```

### 接缝：说话的那条线和控制的那条线是分开的

```mermaid
flowchart LR
    C["调用方"] -->|"开工：编排 + 身份 + 父 agent"| E["引擎"]
    E -->|"活的运行句柄<br/>要结果 · 取消 · 处置"| C
    E -.只观察.-> O["观察方<br/>界面 · 遥测 · 审计"]
```

虚线那一侧只看得见**发生了什么**，看不见那个运行句柄。所以一个装了观察者的插件不可能取消别人的运行——这是接缝上最要紧的一条分工。

```mermaid
flowchart TB
    S["开始<br/>身份验过了"] --> P["进了一个阶段"]
    P --> L["说了一句话"]
    L --> AS["派出一个子 agent"]
    AS --> AE["那个子 agent 结清了"]
    AE --> N["结束<br/>为什么停 · 派了几个"]
```

阶段只是**进度分组**，对执行结构一个字都没说；派出与结清按序号配对，无论怎么停都得配上。

### 六条边围着一次运行凑成一份账，这份账有人查

```mermaid
flowchart TD
    Q1["一次运行的身份自始至终不变"] -.->|"不查会怎样"| A1["中途改名<br/>观察方按序号聚合时，一次运行会裂成两次"]
    Q2["派出与结清逐条配对，身份一致"] -.-> A2["界面上留下永远转圈的子 agent"]
    Q3["收尾时不许有挂着的子 agent"] -.-> A3["引擎在被强杀那条路上偷懒不补结清<br/>没人发现"]
    Q4["报的派出数不小于真看见的"] -.-> A4["计数对不上，用量统计悄悄少算"]
    Q5["完成的不带失败描述<br/>没完成的必须带"] -.-> A5["一次静默的失败<br/>说失败了却说不出为什么"]
```

```mermaid
flowchart LR
    A["这份检查有一个专属的调用点"] --> B["跑在那圈兜底的观察者之前"]
    B -.->|"一条被兜底吞成一行日志的检查<br/>等于没有检查"| B
    C["观察者自己炸了"] -.->|"各自兜住，不饿着后面的同侪<br/>也改变不了那次运行"| C
```

Ralph 不经过这条接缝：它的编排就是一个循环，没有脚本、没有引擎。

## Ralph 那条循环

### 一次调用的主干

```mermaid
flowchart TD
    A["校验入参，立起这次调用的状态"] --> B["为当前轮排出提示词"]
    B --> C["开一个受父作用域约束的全新孩子"]
    C --> D["等它结清，解析这一轮的报告"]
    D --> E{"这一轮说什么"}
    E -->|"还要继续"| F{"轮次还有吗"}
    F -->|"有"| B
    F -->|"用光了"| G["收场：轮次用光<br/>交回最后那份还说有活儿没干完的报告"]
    E -->|"完成了"| H["收场：报完成"]
    E -->|"卡住了"| I["收场：报阻塞"]
    D -->|"这一轮失败 / 被取消"| J["明确终态，不含糊"]
```

```mermaid
sequenceDiagram
    participant P as 父 agent
    participant R as Ralph 工具
    participant K as 这一轮的孩子
    participant W as 共享工作区
    P->>R: 目标 + 最多几轮
    R->>K: 六段提示词（目标 + 第几轮 + 上一轮交接）
    K->>W: 先看，再动手，再核对
    K-->>R: 一份五个字段的结构化报告
    R->>R: 校验、算字数、判定性
    Note over R,K: 孩子一结清就放掉<br/>取消也照放：那时候恰恰最该收干净
    R-->>P: 一段说清收场的文字
```

```mermaid
stateDiagram-v2
    [*] --> 推进中: 第一轮开工
    推进中 --> 推进中: 报「还要继续」，换一个新人
    推进中 --> 报完成: 拿得出证据
    推进中 --> 报阻塞: 没人插手就推不动了
    推进中 --> 轮次用光: 预算烧完，最后一轮还说有活儿
    推进中 --> 这一轮失败: 孩子压根没交出报告
    报完成 --> [*]
    报阻塞 --> [*]
    轮次用光 --> [*]
    这一轮失败 --> [*]
```

## 能力边界

```mermaid
flowchart TD
    Y["这两个包做的"] --> Y1["定下一次编排运行怎么开工、怎么结清、往外说什么"]
    Y --> Y2["把一个不变的目标反复交给全新的人，直到有个结论"]
    N["不做的"] --> N1["Ralph 是固定控制流<br/>不是一门通用的编排语言"]
    N --> N2["不持久化进行中的轮次<br/>进程重启后接不上，只能重开一次循环"]
    N --> N3["不自己挑外部模型，也不自己发工具权限<br/>孩子仍受宿主配置约束"]
    N --> N4["不保证孩子报告的事实正确<br/>完成和阻塞都是它自己说的"]
    N --> N5["不碰工作区<br/>那是孩子手上的工具去读写的"]
    N --> N6["不做后台化<br/>要后台就用普通的子 agent 派发"]
```
