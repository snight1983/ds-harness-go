# Skill、提示词与预设

对应包：`feature/skill`、`feature/skill/skilltool`

## 定位

同一件事，交给一个没被教过的模型和一个被教过的模型，做出来差得很远。「先跑一遍构建再改」「这个仓库的提交信息不许出现某几个词」「结账之前先跑一次对账」——这类话不是函数，是**做法**。

```mermaid
flowchart LR
    subgraph N["没有 Skill"]
        A1["用户：帮我发一版"] --> A2["模型自己猜流程"] --> A3["漏掉一步<br/>或者用了一套别人的规矩"]
    end
```

```mermaid
flowchart LR
    subgraph Y["有 Skill"]
        B1["用户：帮我发一版"] --> B2["模型看见一行目录<br/>「发版：这类任务这么做」"]
        B2 --> B3["把那份说明读进来"] --> B4["照着做"]
    end
```

工具和技能回答的是两个不同的问题：

```mermaid
flowchart TD
    Q1["模型「能做」什么"] --> T["工具<br/>一个能调起来的动作"]
    Q2["这类任务「应该怎么做」"] --> S["技能<br/>一段读完照着做的说明"]
    T -.->|"调它会真的发生一件事"| T2["改文件、发请求、起进程"]
    S -.->|"读它只改变模型的想法"| S2["它仍然只能用手上那些工具"]
```

这一篇讲的是那段说明怎么被找到、谁看得见它、以及它什么时候出现在模型眼前。它顺带串起系统提示词、Agent 预设和运行时上下文这三处——那三处各自另有文档，这里只说它们和技能的关系。


两个包的分工：


## 模型这一侧的三条通路

```mermaid
flowchart TD
    A["每一步之前"] --> A1["发布一份「当前可用技能」的名字与说明"]
    B["模型按准确名字调那件工具"] --> B1["拿回最新的正文和资源提示"]
    C["用户自己那句话里出现 /名字"] --> C1["把那份正文作为注入指令挂在这一步末尾"]
    A1 -.->|"目录里只有摘要"| B
    C1 -.->|"这条路不经过目录，也不经过那件工具"| C2["于是「只许人调、不许模型调」的技能<br/>只有这一个入口"]
```

### 发不发、发第一版还是发替换版

### 注入的次序：背景在前，要照着做的在最后

```mermaid
flowchart LR
    A["工作区规则"] --> B["运行期策略"] --> C["技能目录"] --> D["用户点名的那份技能正文"] --> E(("模型的回答"))
    D -.->|"离回答最近的位置<br/>留给它必须照着做的那份材料"| E
```

这个位置不是靠约定维持的，是靠装配次序钉死的：

```mermaid

    B["② 再装「用户点名」那条"] --> B1["先装的在外层"]
    C["③ 最后装目录那条"] --> C1["于是外层拿到的是内层已经把目录挂好的那份消息<br/>它只管往后接"]
    D["中途装不上"] -.->|"按反序摘干净再报错"| D
```

## 失败语义

这里的东西全都是**喂给模型看的材料**，所以失败处理有一条统一取向：**宁可少给，不给错的**。

```mermaid
flowchart TB
    A["发现结果不完整"] --> A2["不覆盖上一份完整缓存<br/>下次请求再试"]
    B["预设里有一项装不上"] --> B2["整份预设回滚<br/>不留半套能力"]
    C["那件读技能的工具当前不可见"] --> C2["目录跟着消失<br/>不提示模型去调一个不存在的入口"]
    D["日志里旧的目录记录读不回来"] --> D2["当成「不是本模块发的」<br/>下一步重新建，不让会话失败"]
```

分界在于**这一次失败会不会让模型据以行动**：

```mermaid
flowchart LR
    A["目录少一条"] --> A1["模型顶多不知道有这个技能"] --> A2["可以容忍"]
    B["预设装了一半"] --> B1["模型拿到一组互相矛盾的能力"] --> B2["必须整体回滚"]
```

```mermaid
flowchart TD
    E["其余几条"] --> E1["名字、说明、提供方自称的身份<br/>在进目录之前就校验，不指望模型容错"]
    E --> E2["同层重名直接报错；跨层重名才按「近的盖远的」解释"]
    E --> E3["给人看的那几行说明坏了，不阻止预设被发现<br/>能力清单坏了，禁止装载"]
    E --> E4["在步骤监听器里抛错，会让这个会话之后每个回合都失败<br/>所以那里只降级，不抛"]
```

## 能力边界

```mermaid
flowchart TD
    Y["这两个包做的"] --> Y1["把各处报来的清单合起来、定同名的赢家"]
    Y --> Y2["按作用域圈出「这个 agent 看得见哪些」"]
    Y --> Y3["在三条通路上把说明送到模型眼前"]
    N["不做的"] --> N1["不执行技能，也不驱动那圈对话循环<br/>技能是读完照着做的话，不是能调的函数"]
    N --> N2["不产出技能，也不读一个字节的磁盘<br/>从哪来是提供方要回答的"]
    N --> N3["不下载、不编译、不动态加载代码"]
    N --> N4["不为技能正文作保<br/>它能干成什么仍由宿主给的工具与数据权限决定"]
    N --> N5["不管这些文字占掉多少预算<br/>计量和压缩各有各的归属"]
    N --> N6["不把宿主机目录默认摊给 agent"]
```
