# 嵌入现有 Go 服务

## 接入目标

宿主把这套运行时当作**进程内的一个组件**用，而不是启动一个固定形态的独立应用。

```mermaid
flowchart LR
    subgraph H["宿主继续拥有"]
        H1["服务的启动与关闭"]
        H2["HTTP · WebSocket · RPC · 消息队列"]
        H3["用户身份、租户、权限"]
        H4["模型账号与路由配置"]
        H5["业务工具、Skill、人格"]
        H6["数据库、对象存储、密钥服务"]
    end
    subgraph R["运行时拥有"]
        R1["Agent 怎么执行"]
        R2["会话是什么语义"]
    end
    H -->|"装配"| R
    R -.->|"不接管左边任何一项"| H
```

```mermaid

    S3 --> S4["④ 提供会话存储<br/>接好创建、事件、落盘、释放这几条边"]
    S4 --> S5["⑤ 建状态计算名册<br/>在已打开的领域存储上建状态缓存"]
    S5 --> S6["⑥ 建模型运行时，注册模型适配器"]
    S6 --> S7["⑦ 建提示词、工具、会话、Agent 名册"]
```

## 验这份装配真的活着

装完了不等于跑得动。一棵装好的树要过的最低那道线是三件事连起来：

```mermaid
flowchart LR
    A["装得起来"] --> B["跑得完一轮"]
    B --> C["关得干净"]
```

`harness/smoketest` 就是这条线的那把尺子：给它一棵已经公布的树，它送一句话进去、等整棵树静下来、把最终那句回答和这一轮的 token 记账交回来。

```mermaid
flowchart TD
    A["先等它静下来<br/>此刻起的事件才算数"] --> B["挂上事件观察者"]
    B --> C["把那句话送进去"]
    C --> D{"看见它进收件箱了吗"}
    D -->|"还没"| E["这条不算<br/>它属于别的活动"]
    D -->|"看见了"| F["从这里开始记账"]
    F --> G["等整棵树静下来"]
    G --> H["撤观察者、刷盘"]
    H --> I["最终文本 ＋ 用量"]
```

### 那道闸为什么必须有

```mermaid
flowchart LR
    A["等静下来，等的是<br/>「这一层没活动了」"] --> B["不是「我这条消息落地了」"]
    B --> C["没有那道闸的话"]
    C --> D["一次冒烟会把上一轮<br/>还没收敛的尾巴算进自己的账"]
```

### 对树只有一条要求

```mermaid
flowchart TD
    A["恰好一个顶层 agent"] --> B{"多一个怎么办"}
    B -->|"报错（当前做法）"| C["装配方自己去说清是哪一棵"]
    B -->|"随便挑一个"| D["挑错了，后面所有断言<br/>验的都是另一棵树"]
```

### DSH 那台冒烟机有三样没有移过来

```mermaid
flowchart LR
    A["起一个子进程"] --> Z["Go 这边不存在"]
    B["按环境变量在「源码态」和「构建态」<br/>两条启动路径之间二选一"] --> Z
    C["等一个干净的退出码"] --> Z
    Z --> Y["没有那种加载器<br/>没有那份配置文件<br/>编出来就一个可执行文件"]
```

```mermaid
sequenceDiagram

    participant R as Agent 名册
```
